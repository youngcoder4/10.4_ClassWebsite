# Images

- `booktitle.jpg` — the cover of **Người mẹ đất thép**. Shown on `library.html` and
  `book.html` (referenced by that exact filename).

If this file is missing, both pages fall back to a text placeholder automatically,
so nothing breaks. To swap the cover, replace `booktitle.jpg` (keep the name) or
update the `src` in `library.html` and `book.html`.
