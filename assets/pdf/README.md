# PDFs (gated download)

Put the book file here. It is only served to signed-in, email-verified accounts
(the "⬇ Tải sách" button on `book.html`).

- `book.pdf` — the full book **Người mẹ đất thép**.

Note: the **"Info about character"** button no longer uses a local PDF — it opens an
external flipbook (*NHỮNG ANH HÙNG TRÊN VÙNG ĐẤT THÉP*) in a new tab. It is still
gated behind login. No `character.pdf` is needed anymore.
